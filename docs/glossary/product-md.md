# PRODUCT.md

PRODUCT.md is the file at the project root that holds durable product truth: who the product serves, what it does, its brand commitments and its [platform](platform.md). `/impeccable init` writes it through a short interview, and it carries a `<!-- impeccable:product-schema N -->` stamp naming the schema version it follows. `impeccable context` loads it at the start of every session.

Not to be confused with [DESIGN.md](design-md.md), which records the visual system, or a [surface brief](surface-brief.md), which records one surface's strategy. PRODUCT.md holds no [mode](mode.md).

See [Set up a project](../client/set-up-a-project.md). The interview and template are in [init.md](../../skill/reference/init.md).
