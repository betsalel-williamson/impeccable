# Glossary

This glossary is for anyone who uses Impeccable or contributes to it and meets a term in a command, in skill text or in these docs that could be misread. A term earns an entry when it is specific to Impeccable, or when Impeccable uses a common word in a narrower sense than usual. General web and design vocabulary stays out. When unsure, a term gets a short entry. Each entry defines the term, names what it is often confused with and links to the guide that covers it in depth.
