# Mode

A mode names what the visitor's success looks like on one surface: **Persuade** (the visitor decides and acts), **Operate** (completes a task), **Read** (understands something) or **Experience** (is inside the work itself). The agent chooses it from the requested surface, never from the product as a whole, and records it only in that surface's [surface brief](surface-brief.md). Mode also sets the [build path](build-path.md): Operate and Read surfaces build code-led.

Not to be confused with the retired register axis (brand or product). A `## Register` section in PRODUCT.md is reported as deprecated at boot and nothing reads it. Also distinct from [platform](platform.md), which names the delivery target.

See [Modes](../features/modes.md). The Modes section of [SKILL.src.md](../../skill/SKILL.src.md) holds the definitions the agent reads.
