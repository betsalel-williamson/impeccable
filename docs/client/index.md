# client

The client guide is for developers and designers who use a coding agent such as Claude Code, Cursor, Codex or Gemini CLI and want Impeccable in their project. It covers installing the skill, setting a project up, running commands and the detector, iterating in live mode, native apps, what goes over the network, and fixing a setup that drifted. Product guarantees live in the features guide and contributor docs in the developer guide; the first page below links both.
