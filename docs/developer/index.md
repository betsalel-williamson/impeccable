# Developer guide

This guide is for contributors to the Impeccable repository: people and coding agents who change the skill source, the Rust engine, the build, the tests, or these docs. It covers where things live, how to build and test a change, the workflows for adding a command or a detector rule, how releases are cut, and the house rules for prose and pull requests. Product behavior and contracts live in the features guide (`docs/features/`); end-user setup lives in the client guide (`docs/client/`).
